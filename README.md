Sobre o projeto

Este projeto apresenta uma página para uma clínica de saúde, com informações sobre a clínica, especialidades, equipe e formas de contato. O objetivo é praticar desenvolvimento web, layout responsivo e organização de conteúdo.

Funcionalidades
Apresentação da clínica e de sua missão
Lista de especialidades e serviços
Seção da equipe médica
Formulário de contato / agendamento (demonstrativo)
Localização e horário de atendimento
